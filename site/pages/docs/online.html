The optional companion, openppc-online

OpenPPC never goes online. Some jobs need the network, like checking a landing page or downloading an account's reports, so they live in a separate install with its own command: openppc-online. It is not released yet.

What it promises

  • Off unless you install it and run it. Installing openppc never installs it, and OpenPPC never calls it.
  • Read-only. It reads reports and pages. It never creates, changes or deletes anything in an ad account or on a site.
  • Your own credentials. It uses API keys and tokens you create, kept on your computer. OpenPPC never ships, proxies or stores one.
  • Only the hosts it declares. Each command lists every host it connects to, and its tests hold it to that list.

The app on your computer

$ openppc-online app

Opens the same app as openppc.si/app, served from your computer on 127.0.0.1. Audits and checks still run in the browser tab. It adds two views the website doesn't have: Site, which checks a landing page from a form, and Download, which downloads an account and opens the audit with its files.

Check a landing page before ads point at it

$ openppc-online site https://example.com
$ openppc-online site https://example.com --render --format html --out site.html

Crawls the site and checks what a landing page needs: search basics, broken links and redirects, indexing, structured data, HTTPS and security headers, which AI crawlers may read it, and the tracking tags in its pages. With --render, a real browser shows which tags fire before and after the consent banner, the events they send, accessibility problems and lab Web Vitals. The report is scored, and every number in it is traced, as in an audit.

It reads robots.txt first and obeys it, names itself in every request, and refuses private and cloud metadata addresses. Check only sites you own or may check.

Download an account with your own API access

$ openppc-online fetch google 123-456-7890 --out exports
$ openppc audit search-term-waste exports/search_terms.csv

Downloads a Google Ads, Microsoft Advertising or Meta account's reports through the platform's API and writes them as the files OpenPPC audits, then prints the audit command for each. The audit itself stays offline, the same as for an export you downloaded yourself.

The credentials come from environment variables, never the command line, and never reach a file, the output or an error. Each platform's calls are checked against a fixed list before connecting, and none of them can change the account.

Tag Inspector extension

A Chrome and Edge extension: click it on a page to see the tags it loaded and fired, the events they sent, its consent banner and Consent Mode states, and its search basics. It reads the page only when you click, stores nothing and contacts no host. It is not in a store yet.

WordPress plugin

OpenPPC Site Check adds five checks to Tools, Site Health: search engines may index the site, the home page has the search basics, its tags, a consent banner when there are tags, and a sitemap in robots.txt. It reads only its own site and adds no settings. It is not in the plugin directory yet.

Install

The companion is not released yet. Once it is:

$ pip install openppc-online

Until then, it runs from a clone of the repository, where its README has every command, flag and host, and its threat model what each part guards against.
