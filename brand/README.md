# OpenPPC brand

The OpenPPC logo is an auditor's tick: the mark an auditor writes beside a figure once it has been traced back to its source.

## Files

| File | Use |
|---|---|
| `openppc-logo.svg` | The logo, on light backgrounds |
| `openppc-logo-reverse.svg` | The logo, on dark backgrounds |
| `openppc-logo-ink.svg`, `openppc-logo-white.svg` | One colour, for print or photos |
| `openppc-mark.svg`, `openppc-mark-white.svg` | The tick on its own |
| `openppc-wordmark.svg`, `openppc-wordmark-white.svg` | The name on its own |
| `openppc-icon.svg` | App icon and favicon, with rounded corners |
| `openppc-icon-square.svg` | Square app icon, for stores and directories that round the corners themselves |
| `png/` | `favicon.ico` (16, 32 and 48 px), favicon PNGs, `apple-touch-icon.png` (180 px), square icons at 192 and 512 px, a rounded icon at 512 px, and the logo 1600 px wide |
| `social/` | `og-image.png` (1200 x 630) for link previews, `github-social-preview.png` (1280 x 640) |

## Colours

| Name | Hex |

## Type

The wordmark is Source Serif 4 SemiBold, converted to outlines, so the files need no font installed. Source Serif 4 is available under the SIL Open Font License.

## Using the logo

- Keep clear space around the logo at least as tall as its capital P.
- Below 96 px wide, use the icon instead of the full logo.
- Don't recolour, stretch or rotate it, or add shadows or effects.
