# Negatives that block your own keywords

**What the audit found:** {found}

## Why it matters
A keyword blocked by a negative can't show at all. You think you're covering that search, but you're not.

## How to fix it in Google Ads
1. For each conflict, decide which is right: the keyword or the negative.
2. If the keyword is wanted, remove the negative, or narrow it to exact match so it only blocks the search you meant.
3. If the negative is right, pause the keyword.

## Check before you change anything
Negatives don't cover plurals or misspellings, so a narrower negative may need several variants. Shared negative keyword lists aren't checked yet: look at those by hand.

## How to tell it worked
The next audit shows no conflicts, and the unblocked keywords start getting impressions.
