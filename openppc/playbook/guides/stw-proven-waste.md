# Search terms proven to waste money

**What the audit found:** {found}

## Why it matters
These searches keep paying for clicks that don't turn into leads or sales. The waste model compares each term with your own account, not an industry rule of thumb, and only calls a term proven once the evidence is strong. Each one left running keeps spending at the same rate.

## How to fix it in Google Ads
1. Open Campaigns, then Insights and reports, then Search terms, and set the same date range as the audit.
2. Tick the terms listed above, then choose Add as negative keyword.
3. Add each as an exact match negative, written in square brackets, for example [free plumbing estimate]. Exact negatives block that search only, so they can't stop good searches.
4. Add them at the campaign level, or to a shared negative keyword list if the same terms show up in several campaigns.

## Check before you change anything
- Brand searches are never on this list. If your brand name was not given to the audit, check that none of these terms is your brand or a misspelling of it.
- Negatives don't cover plurals or misspellings. If a term has close variants that also waste money, add those too.

## How to tell it worked
Run the same audit on next month's export. These terms should be gone from the report, and the account's wasted spend should be lower.
