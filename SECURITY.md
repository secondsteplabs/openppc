# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately on GitHub: open the repository's
**Security** tab and choose **Report a vulnerability**. Only the maintainers see the report.

Tell us:

- what you found and where
- steps to reproduce it
- the impact you expect

We will reply as soon as we can, usually within a few days.

## Keys and secrets

This project never needs real keys committed to it. If you spot a key anywhere in the code or its history, tell us and we will rotate it.
